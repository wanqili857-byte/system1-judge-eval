# T5：把「判断」做成可复现的微调闭环

T1 留下一句反问：**判据写得这么清楚，手写正则就够了，为什么还要微调一个模型？**

这一支把那个反问做成了实验：同一份判据、同一份题，跑三条臂——手写正则、未微调基座、微调后的模型——
**并强制并列三条常量基线**（全判 allow / 全判 ask / 全判 deny），看「微调」到底买到了什么、没买到什么。

**结论一句话**：微调确实把判别力做出来了（严格命中与平衡准确率同时越过全部常量基线），
但**增益集中在规则失效的那一段**；出了这个域，模型反而比「全判多数类」更差。

> ⚠️ 与 T1 一样，这是一份**单点实测记录**。样本量在一百条量级（一个条目 = 1 个百分点），
> 引用任何数字前请先读 [`REPORT.md`](REPORT.md) 的 §9「局限」——那里有十余条，其中几条会直接改变结论的强度。

## 复现

```bash
pip install pyyaml
python3 scripts/policy.py --selfcheck        # 判据表可执行版自检（期望 55/55）
python3 scripts/eval_tolerant.py --data dataset/t5_synth_public.jsonl --pred <你的预测文件>
```

`eval_tolerant.py` 会**强制并列**常量 ask / deny / allow 三行。没有这三行的评测表不要引用——
这个任务里 `ask` 在两个可选集里都出现，常量 ask 会把容忍命中、危险漏放、误杀三项头条全部追平。

完整闭环（造数据 → 训练 → 评测 → 审计）的命令在 `REPORT.md` §10；那些步骤需要私有的原始数据，
公开件只够复核**判据与数据形态**。

## 诚实边界（摘）

完整列表见 `REPORT.md` §9。最容易影响判断的几条：

- **样本量小**：留出集一百条量级，一个条目 = 1 个百分点。
- **口径会骗人**：容忍命中在「常量 ask」下是 100%（上界），头条只用**严格命中 + 平衡准确率**。
- **分层要连常量一起看**：`rulefail` 层的标签分布偏斜，**常量 deny 在该层的严格命中高于微调模型**。
- **权重不可逐字节复现**：训练未固定 torch 随机源。可复现的是**数据**，不是权重。
- **公开集不是训练集的子集**：它多 9 条且路径已改写，用它重跑得不到本报告里的那份权重。
- **微调不是在每一层、每一个指标上都赢**：`rulefail` 层微调与基座严格命中打平。
